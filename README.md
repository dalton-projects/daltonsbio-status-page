# daltonsbio-status-page

The page at https://status.daltonsbio.com for D'Alton's School of Bio-Energy Healing.

`index.html` is the whole page. It reads the check results from
[dalton-projects/daltonsbio-status](https://github.com/dalton-projects/daltonsbio-status),
where Upptime checks the site every five minutes and opens an issue when a part goes down.
Incident notes are comments on those issues.

Served by GitHub Pages from `main`. It is kept apart from the Upptime repository because
Upptime rewrites that repository's workflows and pages on its own.
